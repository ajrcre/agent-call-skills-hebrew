# Mode: unscripted call (שיחה לא מתוסרטת)

The agent has a **goal + facts + constraints** and conducts a free conversation. Use for: booking appointments, customer service, inquiries, negotiating, getting information.

## Required before the call
- [ ] Goal in one sentence (what "done" looks like)
- [ ] All facts the other side may ask for (names, ID numbers, dates of birth, member / order numbers, address)
- [ ] Hard constraints (what must never be accepted) and soft preferences (ordered)
- [ ] What the agent may agree to on its own, and what needs the requester's OK
- [ ] What never to give (payment details, passwords, unrelated personal info)
- [ ] Persona name + gender; who the agent represents

## How to run
1. Introduce: name + "calling on behalf of …" + goal in one sentence.
2. Answer questions from the facts list only. Unknown → "אֶבְדֹּק וְאַחֲזֹר" – never invent.
3. State hard constraints early.
4. Before ending: read back what was agreed (date, time, place, reference number).

## Cases & responses (generic)
| Case | Response |
|---|---|
| IVR / menu | Pick language, then the relevant menu; ask for a human early |
| Asked for info not in the facts | Don't invent; say you'll check and get back |
| Offer violates a hard constraint | Decline politely, ask for alternatives, write them down |
| Nothing fits | Collect the offered options and end politely – no booking |
| Asked for payment / password | Refuse; say the member will handle it directly |
| Put on hold | Wait; if very long, ask for a callback |
| Call drops | Report to requester; retry only if allowed |
