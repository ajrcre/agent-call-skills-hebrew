# Mode: scripted call (שיחה מתוסרטת)

The agent says **pre-written lines in a fixed order**. Use for: pranks, announcements, invitations, surveys, reminders – anything where the wording matters.

## Required before the call
- [ ] Full list of lines, in order, **with full niqqud**
- [ ] Persona name + gender; callee name + gender (or `unknown`)
- [ ] For each line: expected answers and the prepared reply to each
- [ ] Mandatory lines (must be said no matter what) and the closing
- [ ] What counts as success

## How to run
1. Say line 1, stop, wait for the full reply.
2. Match the reply to a prepared branch (yes / no / question / other). Use the prepared reply; improvise only briefly for "other", then return to the script.
3. Never skip a mandatory line. Never read two lines in one go.
4. Closing lines with a short pause between them.

## Cases & responses (generic)
| Case | Response |
|---|---|
| Callee asks "who is this?" | Repeat persona name + one-line purpose |
| Callee asks "is this a robot / AI?" (sincerely) | "כֵּן, אֲנִי עוֹזֶרֶת AI" – then continue or end politely |
| Callee is busy | Offer to call back later; end |
| Callee goes off-script | Short natural answer, then return to the next line |
| Callee upset | Calm phrase, then skip to closing |
| Voicemail | Hang up immediately, say nothing |
