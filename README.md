# Agent Call Skills – Hebrew 🇮🇱📞

סקילים לסוכני AI שמבצעים **שיחות טלפון בעברית**: כללי ליבה לכל שיחה, ועליהם "התמחויות" (מודולים) לסוגי שיחות ספציפיים.

נבנה תוך כדי שימוש אמיתי (אוקטובר 2026) – כל כלל כאן נולד משיחה שעבדה או שלא.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `SKILL.md` | כללי הליבה – חלים על כל שיחה |
| `specializations/prank.md` | מתיחה / שיחת הפתעה משפחתית |
| `specializations/hmo_appointment.md` | קביעת תור בקופת חולים |
| `voices.md` | בחירת קול (גבר/אישה) ומגדר דקדוקי |
| `CONTRIBUTING.md` | איך מוסיפים התמחות חדשה |

## איך משתמשים

1. טוענים את `SKILL.md` להנחיות (system prompt / mission) של סוכן השיחה.
2. מוסיפים את קובץ ההתמחות הרלוונטי.
3. ממלאים: שם הפרסונה, מגדר הדובר, מגדר הנמען, מטרת השיחה, השורות המוכנות (עם ניקוד מלא!), וסגירה.

## עקרונות בקצרה

- שורה אחת בכל פעם, מחכים לתשובה.
- שם אנושי לפרסונה (למשל מִיקָה), אבל כנות: אם שואלים ברצינות – "אני עוזרת AI".
- ניקוד מלא על כל שורה כתובה מראש.
- מגדר: גם של הדובר וגם של הנמען. לא ידוע? ניסוח ניטרלי.
- תא קולי → מנתקים מיד, לא משאירים הודעה.
